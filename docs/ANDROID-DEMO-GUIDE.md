# Как собрать и показать Android-MVP

Инструкция рассчитана на Windows 10/11 и Android-телефон с USB. В приложении есть локальный анализ доступных уведомлений, экран демонстрационного счёта, контекстный граф, системная проверка контакта, дополнительный opt-in UsageStats и ручное облачное мнение по категориям сигналов. Это не интеграция с настоящим банком.

## 1. Собрать APK

Открой PowerShell и перейди в каталог проекта:

```powershell
cd "$env:USERPROFILE\Documents\Codex\2026-10-31\new-chat\outputs"
.\build-android.ps1
```

Для компактности APK собран для Android-телефонов с ARM64 (включая современные Xiaomi); desktop/emulator и старые 32-битные ABI в эту сборку не входят. Готовый debug APK появится здесь:

```text
outputs\ContextShield-Android-debug.apk
```

При первой сборке Android SDK/Gradle могут скачивать зависимости, поэтому оставь интернет включённым.

## 2. Установить на телефон по USB

### Вариант A — через ADB

На телефоне открой **Настройки → О телефоне** и несколько раз нажми **Версия MIUI/HyperOS**, пока не появится сообщение о режиме разработчика. Затем в **Для разработчиков** включи **Отладка по USB**. Подключи телефон и выбери **Передача файлов**. Подтверди системный диалог **Разрешить отладку по USB**.

В PowerShell выполни из каталога `outputs`:

```powershell
$adb = "$env:USERPROFILE\Documents\Codex\2026-10-31\new-chat\work\tooling\android-sdk\platform-tools\adb.exe"
& $adb devices
& $adb install -r .\ContextShield-Android-debug.apk
& $adb shell am start -n com.contextshield/.MainActivity
```

В выводе `adb devices` рядом с серийным номером должно быть `device`. Если написано `unauthorized`, разблокируй телефон и нажми разрешение отладки. Если список пуст, переподключи кабель, проверь USB debugging и USB-драйвер Xiaomi/Windows.

### Вариант B — скопировать APK

Открой папку `outputs` в Проводнике, скопируй `ContextShield-Android-debug.apk` в телефон в папку **Download/Загрузки**, открой APK на телефоне и подтверди установку. Если Android спросит, разреши установку приложений из этого файлового менеджера. После установки можно удалить APK из «Загрузок».

## 3. Включить уведомления

1. Открой ContextShield.
2. Нажми **Включить доступ к уведомлениям**.
3. В системном списке включи ContextShield и вернись в приложение.
4. Включи разрешение системных предупреждений, если Android спросит.
5. Попроси другой телефон прислать сообщения в мессенджер, уведомления которого доступны на экране блокировки/в шторке.

ContextShield анализирует только текст, который Android действительно отдал через notification listener. Если мессенджер скрывает preview, приложение покажет, что текста нет; оно не читает внутреннюю базу чатов.

## 4. Показать демонстрацию

На главном экране нажимай отмеченные **синтетические демо-кейсы**:

- **Новый номер + срочный перевод** — показывает опасный контекст, причины, рост графа и приостановку демо-кнопки «Перевести».
- **10 рублей на проезд** — обычная небольшая просьба остаётся ниже порога, кнопка доступна.
- **Предупреждение о мошенничестве** — распознаётся как памятка, а не как сообщение злоумышленника.

Это искусственные примеры для воспроизводимого показа; они проходят локальную модель и ту же policy, но не подделываются под реальные уведомления. Текст synthetic-кейса не сохраняется.

Для живого теста отправь, например, просьбу назвать код из SMS или установить AnyDesk и показать экран. Затем проверь граф, объяснения и уведомление ContextShield. Попроси отправителя отдельно прислать безвредную просьбу о небольшой сумме и сравни исход.

## 5. Дополнительные Android-сигналы

- **Проверка близкого:** нажми кнопку системного выбора контакта, выбери один телефонный номер и убедись, что открылся штатный экран набора. Не нажимай вызов, если тестировать звонок не нужно. Приложение не импортирует адресную книгу и не хранит выбранный номер.
- **UsageStats:** включай только для демонстрации и только после чтения объяснения в приложении. Пользователь вручную включает специальный системный доступ для ContextShield. События за 15 минут запрашиваются только при нажатии **Перевести** и активном эпизоде; один факт remote-support приложения сам по себе не должен блокировать кнопку.
- **Смена имени/ника:** notification API не предоставляет надёжный ID аккаунта для универсального сопоставления. В интерфейсе отображается `UNKNOWN`; совпавший ник не наследует доверие.

## 6. Облачная перепроверка

Она необязательна и никогда не вызывается автоматически.

1. Создай ключ OpenRouter в своём аккаунте и введи его только в поле ключа внутри приложения.
2. Нажми **Передать категории сигналов на проверку**.
3. Проверяется только структурированный summary: классы сигналов, локальные баллы, крупные интервалы времени и результат модели. Тексты сообщений, имена, номера, названия приложений и package ID не входят в payload.
4. Учитывай лимит в 50 попыток, сохранённый локально. Удалить ключ можно отдельной кнопкой.

Не присылай API-ключ в чат и не добавляй его в GitHub. Результат облака отображается как дополнительное мнение, не может включить или выключить перевод.

## 7. Сбросить показ

Нажми **Сбросить сессию и граф**. Удалятся зашифрованные локальные события эпизода и счётчики. Это не удаляет сохранённый OpenRouter-ключ и его счётчик; ключ удаляется отдельной кнопкой.

## Границы текущей версии

Кнопка принадлежит демонстрационной песочнице ContextShield. Настоящая банковская операция не выполняется и не блокируется. Локальная модель обучена на открытом синтетическом наборе: даже высокая оценка на его test split не доказывает качество на реальной переписке. Не используй APK для принятия реальных финансовых решений.
